LangChain Setup

1.Create a new folder
Open it in VS Code
2.Create a new venv
   python -m venv venv
3.Activate venv
   venv\Scripts\Activate
4.Create the requirements.txt
    Install packages from requirements.txt
    pip install -r requirements.txt
5.Verify LangChain installation

A couple of notes for when you actually run this: step 4's activation command (venv\Scripts\Activate) is Windows-specific — on macOS/Linux it'd be source venv/bin/activate instead. And step 5 assumes you'll add langchain (and whatever else you need, like langchain-openai or langchain-anthropic) into that requirements.txt before step 6.
